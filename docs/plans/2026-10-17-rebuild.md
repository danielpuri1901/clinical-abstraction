> This plan uses the module names of 2026-10-17.
> On 2026-10-18 the fourteen modules became six; decision D7.1 in `docs/decisions.md` maps the old names to the new files.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Backbone take-home from scratch in this repository so that documents become an auditable clinical abstraction once, every question is answered by code from that abstraction with a visible interpretation, new documents and retries keep the abstraction correct, and accuracy is measured on synthetic patients with known truth.

**Architecture:** A model reads each document once and cites line numbers; code checks every cited value, merges records into one row per real contact, keeps conflicts as ranges, and does all counting. Questions are parsed by code (patients, dates) plus a calibrated decision model (Jev) that picks enum values, with keyword rules as a second reader; disagreement is printed, never hidden. SQLite stores documents, versioned extractions, per-patient abstractions with a rebuild fingerprint, and saved answers with their plans.

**Tech Stack:** Python 3.12, uv, pydantic 2, anthropic SDK (Claude API, `claude-sonnet-5-5` and `claude-haiku-5-5`), httpx (Jev at `https://api.typesafe.ai/v1/systemone`), SQLite, pytest, ruff, langfuse (datasets and experiments; Daniel's choice on 2026-10-17, replacing inspect-ai).

## Global Constraints

- Python `>=3.12,<3.13`, managed by uv; `uv run --frozen` for every command; ruff `line-length = 130`.
- Dependencies are exactly: `anthropic>=1.13,<2`, `pydantic>=2.14,<3`, `httpx`, and dev `pytest`, `ruff`, `langfuse>=3`. No other package without Daniel's approval.
- Evals compute every score locally and write JSON under `outputs/experiments/`; when `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, and `LANGFUSE_BASE_URL` (or the older `LANGFUSE_HOST`) are set (environment or `~/.config/backbone-take-home/langfuse.env`), the same run is also recorded as a Langfuse experiment with the same scores in the project named `backbone` at `https://cloud.langfuse.com`. Without keys the evals still run; nothing in the repository requires a Langfuse account.
- Tests never call a model. `tests/conftest.py` makes `llm.call_anthropic` and `jev.default_transport` raise `RuntimeError`. So `jev.Jev` must build its `httpx.Client` with `transport or default_transport()` at call time, and functions that take a `call` argument default it to `None` and resolve `call or llm.call_anthropic` at run time, so the patch applies.
- `schema.py` is written in Task 0 and is the contract: field names there win over any name in this plan (for example `Correction.corrected_value` and `replaced_value`, `PlanRequirement.effective_start`, `min_therapy_days_per_week`, `min_patient_present_minutes_per_week`). The abstraction's own plan rows use the short keys `effective_date`, `min_days_per_week`, `min_minutes_per_week`, `week_start_day`, `counted_service_types`.
- Every model call goes through `llm.Budget`: cap `MODEL_BUDGET_USD` (default 10.0) for Claude and `JEV_BUDGET_USD` (default 0.50) for Jev; spend is persisted in `outputs/logs/spend.json`; exceeding a cap raises `BudgetExceeded` and the batch stops.
- Secrets come from the environment or from `~/.config/backbone-take-home/anthropic.env` and `jev.env` (loaded by `llm.load_env_file`). No key appears in the repository, logs, exports, or tests.
- Default extraction model `claude-sonnet-5-5`; development runs use `--model claude-haiku-5-5`. Decision model `jev-latest`.
- Prices (list, 2026-10-17): Sonnet 5.5 $2 input and $10 output per million tokens, cache write 1.25x, cache read 0.05x; Haiku 5.5 $0.10 and $0.50, cache read 0.1x; Jev $0.042 per million input tokens, output free.
- Citations are `DOC_ID Ln` or `DOC_ID Ln-m` with 1-based line numbers; the extraction schema cites lines, never quotes.
- Names state what a thing is or does; no abbreviations; Markdown with one sentence per line; plain dashes, never em dashes; no AI co-author on commits.
- All numbers in docs come from files in `outputs/`; estimates are labelled as estimates.
- The gold scorer `evals/score.py` and the gold files are copied verbatim from the previous repository; the abstraction shape must satisfy them unchanged.

## Review Focus

1. Day-first dates ("30 January 2026"), 12-hour times ("9:00 AM"), and bare times ("1415") in a document: the referee must accept the value, not drop the fact. Pinned in Task 1.
2. A question that names an unknown patient ("Alex Smith") or an impossible date ("February 30"): refuse with the reason, never answer for another patient. Pinned in Task 5.
3. A document whose extraction fails once and succeeds on the next run: the patient is marked incomplete, then rebuilt; no answer becomes more confident because a document is missing. Pinned in Task 4.
4. Two records sharing an encounter id but disagreeing on the date: a conflict flag, both dates kept, both weeks "cannot be determined" when they differ. Pinned in Task 3.
5. A collection-wide question at 2,000 patients: output limited to counts, the first 50 patients, and "N more"; under 1 s. Pinned in Task 5 and measured in Task 7.

  - `cited_lines(item) -> list[int]` helper.

    assert verify.normalize_time("9:00 AM") == "09:00" and verify.normalize_time("1415") == "14:15"
